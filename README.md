## Visualisasi Rules Asosiasi
<img width="827" height="393" alt="image" src="https://github.com/user-attachments/assets/68f0261a-af79-48c6-b9af-c0eb7548a674" />

Visualisasi hasil asosiasi tampil pada bagian bawah pada halaman proses data. Pada gambar menampilkan visualisasi hasil asosiasi berupa network graph dan chart bar. Network graph / Grafik jaringan dapat digunakan untuk menampilkan hubungan antar produk dalam aturan asosiasi. Setiap node mewakili suatu item, dan garis (edge) di antara dua node menunjukkan asosiasi. Tebal garis atau warna bisa menunjukkan kekuatan confidence atau lift. Pada chart bar menampilkan 5 aturan terbesar berdasarkan nilai support dan confidence.
