Persiapan Sebelum Proses Analisis Asosiasi pada Data Kecelakaan
  1. Siapkan file excel data kecelakaan berformat .xlsx
  2. Copy value data tersebut ke file baru dengan nama file 'data_kecelakaan.xlsx'
  3. Terdapat 8 kolom pada file 'data_kecelakaan.xlsx', diantaranya no,waktu kejadian,alamat TKP,pihak yang terlibat,meninggal,luka berat,luka ringan,kerugian materiil. 'no' sebagai nomor tiap data juga id dari setiap data
  4. Save data jika proses pemindahan value data telah dilakukan
Penjelasan Tiap Atribut
  1. Hari : Nama hari dalam satu minggu.
  2. Bulan : Nama bulan dalam satu tahun.
  3. Waktu :
    Dini hari (00:00-03:59)
    Pagi (04:00-10:59)
    Siang (11:00-14:59)
    Sore (15:00-17:59)
    Petang (18:00-18:59)
    Malam (19:00-23:59)
  4. Geometri Jalan : Elemen-elemen fisik yang menentukan bentuk dan tata letak suatu jalan. Geometri jalan terbagi menjadi 6 yaitu lurus, bundaran, simpang 3, simpang 4, jembatan, rel kereta api.
  5. Pihak terlibat : Pihak yang terlibat dalam kejadian kecelakaan. Pihak tersebut antara lain pejalan kaki dan kendaraan seperti roda 2, roda 4, bus, truk,dll.
  6. Tingkat kecelakaan : Dibagi menjadi 3 tingkat yaitu :
    - rendah (setidaknya terdapat 1 atau lebih korban luka)
    - sedang (setidaknya terdapat 1 atau lebih korban luka berat)
    - berat (setidaknya terdapat 1 atau lebih korban meninggal dunia)
  7. Tingkat kerugian materiil : Dibagi menjadi 3 tingkat
    - rendah (Nominal kerugian kurang Rp.1.000.000)
    - sedang (Nominal kerugian antara Rp.1.000.000 - 4.999.999)
    - berat (Nominal kerugian lebih dari Rp.5.000.000)
